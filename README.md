# Nexora

### Connect. Share. Stay Safe.

Nexora is a full-stack social networking platform built with the MERN stack. It allows users to create profiles, share posts, follow other users, save posts, and participate in communities.

## Features

- User authentication and profile management
- Create and view posts
- Follow other users
- Save posts
- Community-based interactions
- Suggested communities and users
- Responsive social networking interface
- Content moderation support
- Secure backend API
- MongoDB database integration

## Tech Stack

### Frontend
- React.js
- Redux
- React Router
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

### Additional
- Python
- Flask
- AI-based content classification
